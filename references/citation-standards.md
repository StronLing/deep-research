# Citation Standards

Standardized citation formats by source type.

## Academic Sources

### Monograph (Book)

**Format**:
```
Author (Year), *Title in Italics*, Place: Publisher, pp.XX-XX.
```

**Examples**:
```
Borgolte, Michael (2014), *Das europäische Mittelalter im Spannungsbogen des Vergleichs*, Berlin: Akademie Verlag, S.123-145.

Maitland, Frederic William (1895), *The History of English Law Before the Time of Edward I*, Cambridge: Cambridge University Press, pp.45-67.

夫馬進 (1997), *中国善会善堂史研究*, 京都: 同朋舎, 第89-112頁.
```

**Notes**:
- Use original language for titles
- Include specific page numbers for quotes or specific claims
- For multi-volume works: Vol.X, pp.XX-XX

### Edited Volume

**Format**:
```
Editor (ed.) (Year), *Title*, Place: Publisher, Chapter Author, "Chapter Title", pp.XX-XX.
```

**Example**:
```
Twitchett, Denis and Frederick W. Mote (eds.) (1998), *The Cambridge History of China*, Vol.8, Cambridge: Cambridge University Press, von Glahn, Richard, "The Economic History of China", pp.180-211.
```

### Journal Article

**Format**:
```
Author (Year), "Article Title", *Journal Name*, Vol(Issue), pp.XX-XX, DOI:xxx.
```

**Examples**:
```
Shaughnessy, Edward L. (1997), "Western Zhou History", in M. Loewe and E.L. Shaughnessy (eds.), *The Cambridge History of Ancient China*, Cambridge: Cambridge University Press, pp.292-351.

Pines, Yuri (2009), "The Everlasting Empire: The Political Culture of Ancient China and Its Imperial Legacy", *Journal of Chinese Studies*, 48, pp.325-330.
```

### Working Paper

**Format**:
```
Author (Year), "Title", Working Paper Series No.XXX, Institution, URL, Accessed: Date.
```

**Example**:
```
Acemoglu, Daron and James A. Robinson (2019), "The Emergence of Weak, Despotic and Inclusive States", NBER Working Paper No.23657, https://www.nber.org/papers/w23657, Accessed: 2026-06-07.
```

**Note**: Always note working paper status and check for published version.

## Official and Government Sources

### Statistical Data

**Format**:
```
Agency (Date), "Indicator Name", Database Name, Accessed: Date, URL.
```

**Examples**:
```
National Bureau of Statistics of China (2024-01-17), "2023年国内生产总值", National Data, Accessed: 2026-06-07, https://data.stats.gov.cn/.

U.S. Bureau of Economic Analysis (2024-02-29), "Gross Domestic Product (Third Estimate), GDP by Industry, and Corporate Profits", BEA.gov, Accessed: 2026-06-07, https://www.bea.gov/news/2024/gross-domestic-product-third-estimate-gdp-industry-and-corporate-profits.
```

### International Organization Data

**Format**:
```
Organization (Year), *Report Title*, Place: Publisher, Dataset Code, Query: Parameters, Accessed: Date.
```

**Examples**:
```
World Bank (2024), *World Development Indicators*, Washington DC: World Bank, WDI, Query: China, GDP growth (annual %), 2020-2023, Accessed: 2026-06-07.

OECD (2024), *Economic Outlook*, Paris: OECD Publishing, Vol.2024/1, Query: China, Real GDP growth, Accessed: 2026-06-07.
```

### Legal and Regulatory

**China Law**:
```
Title (Date enacted), Database, Article X, URL, Accessed: Date.
```

**Example**:
```
《中华人民共和国民法典》(2020-05-28), 国家法律法规数据库, 第1165条, https://flk.npc.gov.cn/, Accessed: 2026-06-07.
```

**US Federal Law**:
```
Title, Pub. L. No. XXX, Stat. XXX (Year), Codified at U.S.C. Title X §XXX.
```

**Example**:
```
Dodd-Frank Wall Street Reform and Consumer Protection Act, Pub. L. No. 111-203, 124 Stat. 1376 (2010), Codified at 15 U.S.C. §78o-7.
```

**Court Decision**:
```
Case Name, Citation (Court Year).
```

**Example**:
```
Marbury v. Madison, 5 U.S. (1 Cranch) 137 (1803).

中华人民共和国最高人民法院 (2023), "指导案例XXX号", 《最高人民法院公报》, 2023年第X期.
```

## Corporate and Financial

### Company Filing

**Format**:
```
Company Name (Date), Form Type (e.g., 10-K, Annual Report), Filing Period, SEC EDGAR / CNINFO / Exchange, Accession No., URL.
```

**Examples**:
```
Taiwan Semiconductor Manufacturing Company Limited (2024-02-06), Form 20-F, Fiscal Year 2023, SEC EDGAR, Accession No. 0001140361-24-006862, https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK=0000813243.

贵州茅台 (2024-03-01), 2023年年度报告, 巨潮资讯网, http://www.cninfo.com.cn/new/disclosure/detail?plate=sse&stockCode=600519.
```

### Patent

**Format**:
```
Inventor (Assignee) (Filing Date), "Title", Patent Office Patent No.XXX, Filed: Date, Granted: Date, URL.
```

**Example**:
```
Smith, John et al. (Assigned to Example Corp) (2020-01-15), "Advanced Semiconductor Manufacturing Process", US Patent No.10,XXX,XXX, Filed: 2020-01-15, Granted: 2023-03-21, https://patents.uspto.gov/patent/10XXXxxx.
```

## Archival Sources

### Archive Document

**Format**:
```
Document Title (Date), Archive Name, Collection Name, Box X, Folder Y, Document ID, Location.
```

**Example**:
```
"Memorandum on Economic Policy" (1978-12-15), National Archives and Records Administration, Record Group 56, Box 12, Folder 3, Document 78-12-15-56, Washington DC.
```

### Digital Archive

**Format**:
```
Document Title (Date), Digital Archive Name, Collection, Item ID, URL, Accessed: Date.
```

**Example**:
```
"Trade Records of the East India Company" (1685), British Library Digital Collections, India Office Records, IOR/E/3/XXX, https://www.bl.uk/collection-items/, Accessed: 2026-06-07.
```

## Technical Standards

**Format**:
```
Organization (Year), "Standard Title", Standard Code:XXXX-YYYY, Edition, URL.
```

**Example**:
```
ISO (2024), "Information technology — Artificial intelligence — AI risk management", ISO/IEC 23894:2023, First Edition, https://www.iso.org/standard/77304.html.
```

## Web Sources (Use Sparingly)

**Format**:
```
Author/Organization (Date), "Title", Website Name, URL, Accessed: Date.
```

**Example**:
```
Federal Reserve Bank of New York (2024-03-08), "Effective Federal Funds Rate", FRED, https://fred.stlouisfed.org/series/DFF, Accessed: 2026-06-07.
```

**Note**: Only for official government/organization websites. Never for news articles, blogs, or aggregators.

## Multiple Citations

### Same Source, Multiple Pages
```
Borgolte (2014), *Das europäische Mittelalter*, pp.123-125, 145, 189.
```

### Multiple Sources, Same Claim
```
This claim is supported by multiple studies: Smith (2019), pp.45-47; Jones (2020), pp.112-115; Lee (2021), pp.78-82.
```

### Ibid. and Op. Cit.

Avoid in modern writing. Use short form:
```
Borgolte (2014), p.156 [referring to same work cited previously]

Borgolte (as cited in Johnson 2020, p.78) [referring to secondary citation]
```

## Citation in Text

### Narrative Citation
```
According to Borgolte (2014, S.123), the feudal system...
Research indicates (Smith et al. 2019, pp.45-47) that...
```

### Parenthetical Citation
```
The feudal system exhibited complex characteristics (Borgolte 2014, S.123).
Multiple studies confirm this finding (Smith 2019; Jones 2020; Lee 2021).
```

### Footnotes

**Format**:
```markdown
This is a claim that requires extensive documentation.¹

---
¹ See Borgolte (2014), S.123-145; Maitland (1895), pp.45-67; and 夫馬進 (1997), 第89-112頁 for comprehensive discussion.
```

## Special Cases

### Personal Communication

**Not citable as authoritative source**. If must reference:
```
Expert Name (Title, Institution), Personal Communication, Date.
```

**Note**: Verify claims from personal communication with published sources before citing as fact.

### Social Media (Official Accounts Only)

```
Organization Name [@handle] (Date), "Post content", Platform, URL, Accessed: Date.
```

**Example**:
```
中国人民银行 [@央行微播] (2024-03-08), "存款准备金率调整公告", 微博, https://weibo.com/pbc, Accessed: 2026-06-07.
```

**Note**: Only for official verified accounts. Never for individual accounts or unverified sources.

## Citation Checklist

Before finalizing:

- [ ] All claims supported by citations
- [ ] Page numbers provided for quotes and specific data
- [ ] Access dates for online sources
- [ ] DOIs included where available
- [ ] URLs verified and functional
- [ ] Original language titles preserved
- [ ] Secondary sources clearly marked
- [ ] Multiple sources for contested claims
- [ ] No prohibited sources in bibliography
