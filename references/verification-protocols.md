# Verification Protocols

Step-by-step procedures for verifying information sources and claims.

## Protocol 1: Chinese Data Dual Verification

**Applies to**: All research involving Chinese statistics, policies, legal texts, or historical claims.

### Procedure

**Step 1: Retrieve Chinese Authoritative Source**
- Query official government database
- Access core journal via CNKI
- Retrieve archival documents
- Document: URL, access date, document ID

**Step 2: Retrieve International Authoritative Source**
- Query OECD/World Bank/IMF databases for economic data
- Search Web of Science/Scopus for academic verification
- Access Brill/Cambridge journals for historical context
- Document: Database name, query parameters, access date

**Step 3: Cross-Validation**
| Scenario | Action |
|----------|--------|
| **Consistent** | Proceed with confidence, cite both |
| **Minor Divergence** (<5%) | Document methodology differences, present both |
| **Major Divergence** (>5%) | Analyze definitions, coverage, timing; explain discrepancy |
| **Contradictory** | Investigate further; prefer primary source; document conflict |

**Step 4: Documentation**
```
Chinese Source: [Agency] (Date), "Title", [URL/Doc ID], Accessed: [Date]
International Source: [Organization] (Date), "Title", [Database], Query: [Params]
Verification Result: [Consistent/Divergent/Conflicting]
Notes: [Methodological differences if any]
```

### Example: GDP Growth Rate

```
Query: China's 2023 GDP growth rate

Step 1: Chinese Source
- National Bureau of Statistics (2024-01-17)
- "中华人民共和国2023年国民经济和社会发展统计公报"
- http://www.stats.gov.cn/
- Figure: 5.2%

Step 2: International Source
- World Bank (2024), "World Development Indicators"
- Query: China, GDP growth (annual %), 2023
- Figure: 5.2%

Step 3: Cross-Validation
- Result: CONSISTENT
- Difference: 0%
- Methodology: Both use production approach

Step 4: Documentation
- Both sources confirm 5.2% growth
- High confidence citation
```

## Protocol 2: Academic Claim Verification

**Applies to**: All academic assertions, theoretical claims, research findings.

### Procedure

**Step 1: Primary Source Retrieval**
- Locate original publication (not secondary summary)
- Verify through academic database (DOI search)
- Access full text (not abstract-only)

**Step 2: Author Authority Check**
| Criterion | Verification |
|-----------|--------------|
| Institutional Affiliation | University/research institute website |
| Publication Record | Google Scholar citation count |
| Peer Recognition | Awards, editorial positions |
| Conflict of Interest | Funding disclosures |

**Step 3: Study Quality Assessment**
- Methodology appropriateness
- Sample size adequacy
- Statistical significance
- Replication status
- Meta-analysis inclusion

**Step 4: Contextual Verification**
- Consensus view in field?
- Dissenting perspectives?
- Temporal validity (superseded by newer research?)
- Scope limitations

**Step 5: Citation Documentation**
```
Author (Year), "Title", *Journal*, Vol(Issue), pp.XX-XX, DOI:xxx
Author Credentials: [Institution, Position]
Study Quality: [High/Medium/Low] - [Brief justification]
Field Consensus: [Consensus/Contested/Novel]
```

## Protocol 3: Legal and Regulatory Verification

**Applies to**: Laws, regulations, policies, court decisions.

### Procedure

**Step 1: Official Database Query**
- China: 国家法律法规数据库 (flk.npc.gov.cn)
- US: Cornell Legal Information Institute
- EU: EUR-Lex
- International: UN Treaty Collection

**Step 2: Version Verification**
- Current version (not historical)
- Amendment status
- Effective date
- Repeal status

**Step 3: Interpretation Cross-Check**
- Academic legal commentary (law reviews)
- Official guidance documents
- Case law application
- Regulatory agency FAQs

**Step 4: Temporal Validity**
```
Law: [Name and Number]
Effective: [Date]
Current Status: [Active/Amended/Repealed]
Latest Amendment: [Date and content]
Citation: [Official database with Article/Clause]
```

## Protocol 4: Corporate and Financial Data

**Applies to**: Company financials, market data, investment claims.

### Procedure

**Step 1: Primary Source Retrieval**
| Data Type | Primary Source |
|-----------|----------------|
| Public Company Financials | SEC EDGAR (US), 巨潮资讯网 (China), Company investor relations |
| Private Company Data | Original funding announcements, company blog |
| Market Data | Exchange official data, Bloomberg/Reuters (verify primary) |
| Patents | USPTO/EPO/JPO patent databases |

**Step 2: Data Freshness Check**
- Publication date
- Reporting period (quarter/year)
- Restatement history
- Auditor opinion

**Step 3: Cross-Validation**
- Exchange data vs. Company filing
- Bloomberg/Reuters vs. Primary source
- Third-party audit confirmation

**Step 4: Forward-Looking Statements**
- Distinguish facts vs. projections
- Identify assumption bases
- Assess probability qualifiers ("may", "will", "expected")
- Document uncertainty

## Protocol 5: Historical Claim Verification

**Applies to**: Historical facts, dates, figures, interpretations.

### Procedure

**Step 1: Primary Source Hierarchy**
1. **Archival Documents**: Original records, contemporaneous accounts
2. **Primary Publications**: Academic monographs with archival research
3. **Peer-Reviewed Articles**: Journal articles with primary evidence
4. **Reference Works**: *Cambridge History*, *Oxford Encyclopedia* (verify citations)

**Step 2: Historiographical Context**
- Identify historiographical school
- Recognize interpretive framework
- Acknowledge revisionist perspectives
- Date the interpretation (older works may be superseded)

**Step 3: Chinese History Special Protocol**
```
Required Sources:
1. International Sinology (English/German/Japanese)
   - Cambridge History of China
   - Harvard Journal of Asiatic Studies
   - Early China journal
   - Brill Sinica Leidensia series
   
2. Chinese Authoritative
   - 中华书局点校本
   - 上海古籍出版社权威版本
   - 《历史研究》《考古学报》等CSSCI顶级期刊
   
3. Cross-Validation
   - Compare Chinese and international interpretations
   - Note differences in framing and emphasis
   - Present both with attribution
```

**Step 4: Source Citation**
```
Archival: [Archive Name], [Collection], [Box], [Folder], [Document ID]
Published: Author (Year), *Title*, Publisher, pp.XX
Archival citation in publication: "According to [Archive document], as cited in Author (Year), p.XX"
```

## Protocol 6: Technical and Scientific Claims

**Applies to**: Engineering specifications, scientific theories, medical claims.

### Procedure

**Step 1: Source Hierarchy**
| Priority | Source Type | Example |
|----------|-------------|---------|
| 1 | Original Research | Peer-reviewed journal article |
| 2 | Technical Standards | ISO/IEC/IEEE standards |
| 3 | Patent Documents | Granted patents with claims |
| 4 | Industry White Papers | Vendor technical documentation |
| 5 | Textbooks | University-level technical texts |

**Step 2: Technical Parameter Verification**
- Specifications from manufacturer datasheet
- Independent testing laboratory results
- Peer-reviewed benchmarking studies
- Standards compliance certification

**Step 3: Scientific Claim Assessment**
- Peer review status
- Replication studies
- Effect size and confidence intervals
- Conflict of interest disclosure
- Pre-registration status

**Step 4: Uncertainty Quantification**
- Confidence intervals
- Error margins
- Assumption sensitivity
- Limitations acknowledgment

## Protocol 7: Real-Time Information Verification

**Applies to**: Breaking news, current events, rapidly changing situations.

### Procedure

**Step 1: Initial Source Assessment (T+0)**
- Verify source authority (official > media > social)
- Check for official confirmation
- Document timestamp
- Flag as [UNVERIFIED] if sole source

**Step 2: Confirmation Window (T+1 to T+24h)**
- Monitor for authoritative source confirmation
- Cross-reference with international sources
- Check for corrections or clarifications

**Step 3: Final Verification (T+24h+)**
- Authoritative sources have confirmed
- Update citation with confirmation date
- Remove [UNVERIFIED] flag
- If unconfirmed, downgrade or remove claim

**Step 4: Documentation**
```
Initial Report: [Source] (Date/Time)
Confirmation: [Authority] (Date/Time)
Status: [Confirmed/Unconfirmed/Refuted]
Update History: [List of updates with timestamps]
```

## Protocol 8: Multi-Perspective Synthesis

**Applies to**: Presenting academic consensus and dissent fairly.

### Procedure

**Step 1: Field Mapping**
- Identify major theoretical schools
- Map consensus areas
- Identify controversy zones
- Locate emerging perspectives

**Step 2: Representative Selection**
- Select leading proponents of each view
- Ensure academic stature parity
- Include recent contributions
- Check for potential bias

**Step 3: Attribution Framework**
```
Consensus View:
- "According to [Authoritative Source A], [Source B], and [Source C]..."
- Cite 3-5 sources representing mainstream

Alternative View 1:
- "[Scholar] ([Year]) at [Institution] argues..."
- Identify theoretical school
- Note following within field

Alternative View 2:
- Similarly attribute

Practitioner View:
- "[Industry Expert], [Title] at [Organization], notes..."
- Distinguish academic from practitioner perspective
```

**Step 4: Synthesis Presentation**
```markdown
## Points of Agreement
[What all sides accept, with citations]

## Active Controversies
| Issue | Position A (Source) | Position B (Source) |
|-------|---------------------|---------------------|
| X | View A | View B |

## Uncertainty and Limitations
[Acknowledge what remains unknown]

## Implications
[Practical consequences of different views]
```

## Quick Reference: Verification Checklist

### Before Using Any Source
- [ ] Not on [source-blacklist.md](source-blacklist.md)
- [ ] Authority level appropriate (Tier 1 or 2)
- [ ] Timestamp current (or explicitly historical)
- [ ] Original source (not secondary summary)
- [ ] Full citation information available

### For Data Claims
- [ ] Cross-validated with independent source
- [ ] Methodology understood and documented
- [ ] Temporal scope defined
- [ ] Geographic scope defined
- [ ] Limitations acknowledged

### For Academic Claims
- [ ] Peer-reviewed (if scientific)
- [ ] Author credentials verified
- [ ] Study quality assessed
- [ ] Replication status checked
- [ ] Conflicts of interest disclosed

### For Legal Claims
- [ ] Official database source
- [ ] Current version verified
- [ ] Effective date confirmed
- [ ] Interpretation cross-checked

### For Historical Claims
- [ ] Primary source or authoritative synthesis
- [ ] Historiographical context provided
- [ ] Chinese topics: dual verification completed
- [ ] Interpretive framework identified

## Emergency Procedures

### When Authoritative Sources Conflict

1. **Document the conflict**: Note both sources and claims
2. **Analyze methodology**: Differences in definitions, coverage, timing
3. **Assess authority**: Which source has stronger methodology?
4. **Present both**: "Source A claims X, while Source B claims Y"
5. **Explain**: Provide analysis of why divergence exists

### When No Authoritative Source Exists

1. **Acknowledge gap**: "No authoritative source was found for this claim"
2. **Present available evidence**: With appropriate caveats
3. **Label uncertainty**: Use qualifiers ("may", "appears to", "reportedly")
4. **Suggest verification**: Note need for further research
5. **Never present as fact**: Maintain epistemic humility

### When Under Time Pressure

1. **Prioritize**: Verify most critical claims first
2. **Flag**: Mark [UNVERIFIED] for claims not yet verified
3. **Document**: Note verification status for each source
4. **Update**: Return to complete verification when possible
5. **Never compromise**: Do not use blacklisted sources regardless of deadline
